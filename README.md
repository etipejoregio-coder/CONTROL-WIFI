# CONTROL-WIFI

Aplicación de escritorio para administrar los dispositivos de una red Wi-Fi propia.

## Funciones previstas
- Detectar dispositivos conectados a la red local.
- Mostrar nombre, IP y dirección MAC cuando estén disponibles.
- Permitir o bloquear dispositivos mediante el control de acceso del router, una vez confirmada la compatibilidad del firmware ZTE ZXHN F620-I8.
- Cambiar la contraseña de las redes Wi-Fi de 2.4 GHz y 5 GHz usando la misma clave.

## Seguridad y compatibilidad
La aplicación no debe guardar contraseñas del router en el repositorio ni enviarlas a servicios externos. Las acciones de bloqueo y cambio de contraseña solo se habilitarán después de verificar el método de administración compatible con el firmware instalado.
